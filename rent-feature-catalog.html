Feature Catalog for Rent Prediction

住宅 月額家賃 予測モデル
説明変数カタログ

月額家賃を目的変数とする予測モデルのための、説明変数候補の網羅的リファレンス。一般物件からハイエンド物件まで、価格帯によって「効き方」が変わる構造を踏まえ、11カテゴリに整理しています。

目的変数 月額家賃（管理費込／別は要設計） カテゴリ数 11 変数候補 約150項目
主効果・基本属性 足切り設備（ないと選外） 付加価値（あると上振れ） ソフト要因（取得難・代理変数化）

01

物件の基本属性

Property Fundamentals
家賃の主効果を担う中核変数群。面積・築年数・所在階の3つで説明力の大部分を占める。面積・間取り・部屋数は相互相関が高く、多重共線性に注意。
  • 専有面積（㎡）最も影響力が大きい単一変数
  • 間取り1K / 1LDK / 2DK / 3LDK 等
  • 部屋数
  • 建物種別マンション/アパート/戸建/テラスハウス
  • 構造RC / SRC / 鉄骨 / 木造
  • 築年数（または築年）
  • 総階数
  • 所在階高層階プレミアム
  • 方角・向き日当たり（南向き等）
  • 角部屋か否か
  • 専有面積に対するバルコニー比率
  • 天井高
  • 梁の出っ張り・柱の食い込み有効面積感に影響
  • 採光面の数2面採光 / 3面採光
  • 窓の数・大きさ
  • リフォーム/リノベ履歴
02

室内設備・仕様

In-Unit Equipment
一般物件では「足切り設備」が下限を規定する。検索フィルタで弾かれると物件情報を見られる前に脱落するため、有無が大きく効く。3大こだわり条件＝「バス・トイレ別」「エアコン」「室内洗濯機置場」。
  • エアコン有無・台数全世帯で必須1位
  • バス・トイレ別
  • 室内洗濯機置場室内/室外の別
  • 独立洗面台
  • 温水洗浄便座
  • 追い焚き機能ファミリーで重要度上昇
  • 浴室乾燥機
  • 床暖房
  • キッチンコンロ口数
  • コンロ種別IH / ガス
  • システムキッチン
  • 食器洗い乾燥機
  • ディスポーザー
  • 収納量WIC / 各室収納
  • トランクルーム
  • バルコニー有無・面積
  • ルーフバルコニー / 専用庭
  • スマートロック / スマートホーム対応
  • アクセントクロス・内装グレード内見時の印象
03

エネルギー・光熱

Energy & Utilities
家賃そのものでなく「実質光熱費」を通じて体感コストを補正する変数群。プロパンガスは光熱費が高く、家賃にマイナス補正されることもある。
  • オール電化か否か
  • ガス種別都市ガス / プロパン
  • エコキュート / 給湯方式
  • 太陽光発電・蓄電池
  • 電気容量（アンペア数）
  • 断熱性能複層ガラス / 内窓 / 断熱等級
  • 遮音性能の高い窓学生・幹線道路沿いで効く
04

立地・アクセス

Location & Access
面積と並ぶ主効果。徒歩分数は非線形（5分と6分の差は大きく、20分と21分は小さい）。緯度経度は空間的自己相関を吸収する補正変数として有用。
  • 最寄駅まで徒歩分数非線形に効く
  • 最寄路線・乗換利便性
  • 複数路線利用可否
  • 都心（主要ターミナル）への所要時間
  • 緯度・経度空間補正・地理座標
  • 行政区・町丁目
  • バス便の要否・本数
  • 前面道路の幅員・道路付け
  • 私道 / 公道
  • 土地の高低差・坂の有無
05

周辺環境・生活利便

Neighborhood & Amenity
エリア相場（地価公示・路線価）を取り込む変数群。同じ設備でもエリアの標準装備率によって差別化効果が変わるため、相場との交互作用が重要。
  • エリア平均賃料相場地価公示 / 路線価
  • 周辺空室率
  • スーパー/コンビニ/薬局まで距離
  • 学区・教育施設小中学校・保育園の充実
  • 医療機関へのアクセス
  • 治安指標犯罪発生率
  • 公園・緑地
  • 嫌悪施設の近接線路/幹線道路/墓地/斎場等
  • 騒音源・振動源からの距離
  • 南側建物による日照阻害
  • 眺望オーシャン/夜景/山ビュー等
  • 電波状況・携帯のつながりやすさ
  • 再開発・将来性
  • 人口動態流入超過 / 流出
  • エリア平均世帯年収
06

災害・耐震・安全

Disaster & Safety
安全性プレミアム／ディスカウントを生む。新耐震・旧耐震の境界は1981年6月で、築年数とは別軸の効果を持つ。セキュリティ設備は「相場より高くても決まる」付加価値の上位常連。
  • 耐震基準新耐震 / 旧耐震（1981年6月境界）
  • 制震・免震構造
  • ハザードマップ上のリスク浸水 / 土砂災害
  • オートロック
  • 防犯カメラ
  • TVモニタ付インターホン
  • 24時間ホームセキュリティ契約
  • 非常用発電・防災備蓄
  • 擁壁の有無・状態

共用施設

Shared Facilities
高級帯で家賃が非線形に上昇する主因の一つ。一般物件ではほぼ存在しないため、価格帯の上限側を識別する変数として機能する。
  • フィットネスジム
  • スパ / プール / サウナ
  • スカイラウンジ / 眺望デッキ
  • ルーフガーデン / 屋上庭園
  • ゲストルーム来客宿泊
  • 会議室 / ワークラウンジ在宅勤務需要
  • コワーキングスペース
  • パーティルーム / キッチンスタジオ
  • シアタールーム / ライブラリー
  • キッズルーム / スタディルーム
  • 宅配ボックスEC拡大で標準装備化
  • エレベーター有無・基数
  • 駐車場 / 駐輪場 / バイク置場
  • 24時間ゴミ出し可単身女性で人気

  • 内廊下 / 外廊下の別
08

ホスピタリティ・サービス

Hospitality & Service
ハイエンド物件の差別化はモノよりサービスに移る。データ取得が難しいため、ブランド名・管理形態を代理変数とする設計が現実的。
  • コンシェルジュ / フロント無し / 日中 / 24時間
  • バイリンガル対応駐在員需要に直結
  • ハウスキーピング・クリーニング取次
  • 朝食サービスサービスアパートメント型
  • 提携医療・健康相談
  • 荷物一時預かり・宅配取次

  • 管理形態常駐 / 巡回 / 自主管理
09

居住者コミュニティ・ピア属性

Resident Community & Peer Effect
見落とされやすいが重要な軸。「誰が住んでいるか」自体が価値（同質性プレミアム）を生む。ハイエンド家賃の「スペックで説明できない上振れ」の正体であることが多い。取得困難なため代理変数化が前提。
  • 同建物内の分譲/賃貸比率
  • 同建物内の平均世帯年収帯
  • 法人契約比率社宅利用＝信用度の代理
  • 外国人居住比率駐在員人気の指標
  • 入居審査の厳格さ年収倍率 / 保証会社グレード
  • 居住者限定コミュニティ・イベント
  • 居住者専用アプリ / 会員特典
  • 管理組合の活発度・修繕積立金の健全性
  • 周辺住民の属性高級住宅街 / 文教地区 / 繁華街隣接

ブランド・建物の格

Brand & Prestige
ネームバリューによるプレミアム。カテゴリ08・09の取得困難なソフト要因を束ねる代理変数としても機能する（ブランド＝サービス水準・居住者層の代理）。
  • 分譲賃貸か否か仕様グレードが高い傾向
  • デベロッパー / シリーズブランド
  • 管理会社
  • デザイナーズ物件か否か
  • 新築 / 築浅プレミアム
  • 建物のランドマーク性
11

契約条件・付帯費用

Contract & Costs
表面家賃と実質負担の差を生む変数群。管理費・共益費は目的変数の定義（家賃に含めるか）と直結するため、最初に設計を固める必要がある。
  • 管理費・共益費目的変数の定義に直結。込/別の設計を最初に確定する
  • 敷金 / 礼金
  • 更新料
  • 保証会社利用要否
  • フリーレント有無
  • 契約形態普通借家 / 定期借家（定借は相場安）
  • 入居者属性の制限女性限定 / 学生限定 / 法人
  • ペット可否 / 楽器相談 / 事務所利用
  • 家具・家電付き
  • 短期解約違約金
  • 受入れ可否生活保護 / 外国人 / 高齢者 → 需要層の広さ
  • ネット無料 / 高速回線10年連続 人気設備1位
  • 募集開始からの経過日数長期化＝強気価格の兆候
  • 即入居可否 / 空室期間

Modeling Notes

モデリング上の要点

この変数群で本質的に重要なのは、同じ変数でも価格帯によって効き方が逆転すること。一般物件では設備は「ないと選外」という減点法で効き、ハイエンドでは「サービス・人的環境・ブランド」という加点法で効く。単一の線形モデルでは捉えきれない。

論点内容と対処
多重共線性面積・間取り・部屋数は高相関。いずれかに集約するか、ツリー系で吸収。
非線形性徒歩分数・築年数は線形でない。決定木 / LightGBM が有効。
空間的自己相関緯度経度・地域ダミーで「立地プレミアム」を吸収。
交互作用「設備 × ターゲット層」「面積 × エリア」「築年数 × 構造」。同じオートロックでも標準装備エリアでは効かない。
カテゴリ変数処理行政区・ブランドは Target Encoding が有効。
欠損の扱いカテゴリ07〜09はスクレイピングで取りにくい。欠損フラグ自体を特徴量化する。

取得難易度で割り切る

ソフト要因（カテゴリ08〜09）は欠損が多い。実装の現実解は次の通り。

  • 取得しやすく効く変数を優先整備 — オール電化、分譲賃貸、定借、ハザード、ネット無料など。
  • 取得困難なソフト要因は代理変数で束ねる — ブランド名・管理会社・分譲賃貸フラグが、サービス水準と居住者層の代理になる。
  • 価格帯でセグメント分割、またはツリー系モデルで非線形・交互作用を一括吸収。

まず押さえる4変数

説明力の大部分は面積・築年数・駅徒歩分数・エリア相場で確保できる。残りの約150変数は、この骨格に精度を上乗せしていく位置づけで捉えるとよい。
